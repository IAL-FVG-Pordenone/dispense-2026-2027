# Dispense 2026-2027

Dispense dei corsi IeFP di IAL FVG Pordenone, anno formativo 2026-2027.
Una cartella per classe, una sottocartella per SST (materia).
Le versioni in altre lingue stanno in una sottocartella per lingua: `ES` spagnolo, `UK` ucraino,
`BN` bengalese, `AR` arabo.

Questo repository si aggiorna in automatico a ogni nuova dispensa.
